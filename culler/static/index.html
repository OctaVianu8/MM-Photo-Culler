Open a folder of RAW / JPEG files to start. Originals are only ever read.

Open folder

    Export to Lightroom

    Writes NAME.xmp next to each RAW with xmp:Rating and a colour label. Lightroom does not read pick/reject flags from files, so picks/rejects travel as labels: in Lightroom select the photos → Metadata → Read Metadata from Files, then filter by label. Existing sidecars are merged (and backed up), originals are never touched.
